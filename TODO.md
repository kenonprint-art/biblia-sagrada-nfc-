# Entregas do projeto

## Página pública e acesso NFC

- [x] A página abre diretamente por um link público, sem cadastro, login ou instalação de aplicativo, para que a URL possa ser gravada na etiqueta NFC.
- [x] A página é construída com HTML, CSS e JavaScript estáticos e está pronta para hospedagem em serviço como o Netlify.
- [x] A interface é responsiva e mobile-first para navegadores atuais de Android e iPhone.

## Base bíblica e sorteio

- [x] A página carrega automaticamente um versículo bíblico aleatório assim que é aberta.
- [x] A base local cobre os 66 livros da Bíblia, incluindo Antigo e Novo Testamento, com livro, capítulo e número do versículo.
- [x] A tradução usada é a Almeida 1911, identificada pela fonte como domínio público.
- [x] O sorteio considera toda a base de 31.101 versículos e evita repetir o versículo imediatamente anterior quando possível.

## Interação e compartilhamento

- [x] O botão “NOVA PALAVRA” carrega outro versículo sem recarregar a página.
- [x] O botão “COMPARTILHAR” abre o WhatsApp com o texto e a referência do versículo preenchidos.
- [x] A pessoa pode pesquisar localmente por palavras, livros ou referências e tocar em um resultado para carregá-lo em destaque.
- [x] A página inclui manifesto web e metadados mobile para poder ser adicionada à tela inicial como atalho, mantendo o acesso sem aplicativo nativo obrigatório.

## Design e experiência

- [x] O visual usa fundo escuro, detalhes dourados, hierarquia tipográfica legível e uma ilustração discreta de Bíblia aberta.
- [x] O versículo fica em destaque dentro de um cartão de leitura, com botões grandes e acessíveis ao toque.
- [x] A página inclui metadados, favicon e manifesto de rota para uma publicação web completa.
